# YOLO Object Tracking Speed Comparison

A computer vision benchmarking project that compares the **tracking speed and real-time performance** of three lightweight YOLO models using the same input video and the same tracking configuration.

## Models

* YOLOv10n
* YOLO11n
* YOLO12n

Each model is evaluated using **ByteTrack** on the same input video to provide a consistent speed comparison.

## Project Objectives

The project aims to:

* Compare the processing speed of different YOLO models.
* Measure Frames Per Second (FPS).
* Measure total processing time.
* Calculate average processing time per frame.
* Determine real-time capability.
* Identify the fastest model for real-time object tracking.

## Technologies Used

* Python
* Ultralytics YOLO
* OpenCV
* ByteTrack
* Pandas
* Matplotlib
* Jupyter Notebook / Google Colab

## Methodology

The same workflow is applied to all three models:

1. Load the input video using OpenCV.
2. Load the YOLO model.
3. Perform object tracking using ByteTrack.
4. Process all video frames.
5. Save the annotated tracking output.
6. Measure total processing time.
7. Calculate FPS.
8. Calculate average processing time per frame.
9. Determine whether the model meets the real-time threshold.
10. Compare the final results using tables and charts.

Using the same input video and tracking configuration helps make the comparison more consistent across the three models.

## Performance Results

The models were benchmarked using the same video and tracking setup.

| Model        |           FPS | Real-Time Capable |
| ------------ | ------------: | :---------------: |
| **YOLOv10n** | **32.80 FPS** |        Yes        |
| YOLO11n      |     28.67 FPS |         No        |
| YOLO12n      |     27.91 FPS |         No        |

### Best Performing Model

**YOLOv10n** achieved the highest processing speed at **32.80 FPS**, making it the only model in this comparison to meet the project's real-time threshold of **30 FPS**.

YOLO11n and YOLO12n achieved **28.67 FPS** and **27.91 FPS**, respectively.

## Evaluation Metrics

### FPS

FPS is calculated using:

```text
FPS = Number of Processed Frames / Total Processing Time
```

A higher FPS indicates faster video processing.

### Average Processing Time

Average processing time per frame is calculated using:

```text
Average Processing Time = Total Processing Time / Number of Frames
```

The result is reported in milliseconds.

### Real-Time Capability

For this project, a model is considered real-time capable when:

```text
FPS >= 30
```
