# YOLO Object Tracking Speed Comparison

A computer vision project that compares the **speed and real-time performance** of three lightweight YOLO models for object tracking using the same input video and the same tracking configuration.

## Project Overview

This project evaluates:

* **YOLOv10n**
* **YOLO11n**
* **YOLO12n**

Each model is used with **ByteTrack** to track objects in the same video. The models are compared based on:

* FPS (Frames Per Second)
* Total Processing Time
* Average Processing Time per Frame
* Real-Time Capability

The goal is to determine which lightweight YOLO model provides the best balance between tracking performance and processing speed.

## Project Workflow

The project follows these steps:

1. Load the input video using OpenCV.
2. Load each YOLO model.
3. Perform object tracking using ByteTrack.
4. Process every frame of the same input video.
5. Save annotated tracking videos.
6. Measure total processing time.
7. Calculate FPS.
8. Calculate average processing time per frame.
9. Determine whether each model is capable of real-time processing.
10. Compare the models using tables and visualizations.
11. Export the final results to a CSV file.

## Evaluation Metrics

### FPS

FPS is calculated as:

```text
FPS = Number of Processed Frames / Total Processing Time
```

A higher FPS indicates faster processing.

### Average Processing Time

The average processing time per frame is calculated as:

```text
Average Processing Time = Total Processing Time / Number of Frames
```

The result is reported in milliseconds.

### Real-Time Capability

A model is considered **real-time capable** when:

```text
FPS >= 30
```
